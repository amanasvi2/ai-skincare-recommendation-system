# AI Skincare Recommendation System

Machine learning project focused on image-based skincare analysis and personalized skincare recommendations.

## Features

- Acne detection
- Skin tone classification
- Skin type prediction
- Product recommendation pipeline
- Image preprocessing and feature engineering

## Models Evaluated

- CNN
- Random Forest
- SVM
